# ZIP Importer

Импорт ZIP-архивов прямо в Content Browser Unreal Engine с сохранением структуры папок, обработкой вложенных архивов и повторным импортом ресурсов из исходного архива.

ZipImporter добавляет импорт ZIP-архивов непосредственно в Content Browser Unreal Engine. Перетащите архив в папку назначения или выберите его через стандартную кнопку Import. Плагин извлекает содержимое архива и передаёт файлы стандартной системе импорта ресурсов Unreal Engine, сохраняя структуру папок. ZIP-архивы внутри других ZIP-архивов обрабатываются рекурсивно. Импортированные ресурсы сохраняют информацию об исходном архиве и могут быть повторно импортированы стандартной командой Reimport, пока исходный архив остаётся доступен. Поддерживаемые типы файлов зависят от импортёров, доступных в проекте. Поддерживается только формат ZIP; RAR, 7z и TAR не поддерживаются.

**Плагин доступен на [Fab](https://www.fab.com/).**

## Возможности

- **Импорт ZIP-архивов в Content Browser.** Перетащите ZIP-архив в нужную папку или воспользуйтесь стандартной кнопкой **Import** в Content Browser.
- **Сохранение структуры папок.** Каталоги из архива автоматически создаются внутри выбранной папки Content Browser.
- **Обработка вложенных ZIP-архивов.** ZIP-файлы внутри архива обрабатываются рекурсивно, а их содержимое помещается в соответствующие подпапки.
- **Использование системы импорта Unreal Engine.** Файлы импортируются с помощью стандартных импортёров ресурсов, доступных в проекте. Поэтому список поддерживаемых типов файлов зависит от Unreal Engine и установленных в проекте импортёров.
- **Повторный импорт из исходного архива.** Каждый импортированный ресурс сохраняет информацию об исходном архиве и своём расположении внутри него. Это позволяет использовать стандартную команду повторного импорта Unreal Engine.

## Использование плагина

### Включение плагина

После установки ZipImporter откройте проект и выполните следующие действия:

1. В меню Unreal Editor выберите **Edit → Plugins**.
2. Найдите **ZipImporter**.
3. Включите плагин.
4. Если редактор предложит перезапуск, перезапустите его.

![ZipImporter в окне Plugins](images/plugin_enabled.png)

### Импорт перетаскиванием

Это самый быстрый способ импортировать архив.

1. Откройте **Content Browser**.
2. Выберите или откройте папку, в которую нужно поместить импортированные ресурсы.
3. Найдите ZIP-архив в проводнике Windows.
4. Перетащите архив в выбранную папку Content Browser и отпустите кнопку мыши.

ZipImporter извлечёт архив и импортирует его файлы в выбранную папку. Вложенные каталоги будут автоматически воссозданы, поэтому исходная структура папок сохранится.

### Импорт через Content Browser

Также можно воспользоваться стандартной кнопкой **Import** в Content Browser:

1. Откройте папку назначения в Content Browser.
2. Нажмите **Import**.
3. Выберите ZIP-архив.

Архив будет обработан так же, как при перетаскивании. Это альтернативный способ запуска импорта, дополнительная настройка не требуется.

### Вложенные ZIP-архивы

Если внутри ZIP-архива находятся другие ZIP-файлы, плагин обработает их рекурсивно. Содержимое каждого вложенного архива помещается в подпапку с его именем. Структура каталогов внутри него также сохраняется.

Например, архив со следующей структурой:

```text
EnvironmentPack.zip
├── Materials/
│   └── Surface.png
├── Meshes/
│   └── Rock.fbx
└── ExtraAssets.zip
    └── Textures/
        └── Detail.png
```

будет импортирован с соответствующей структурой папок внутри выбранной папки Content Browser.

### Повторный импорт ресурсов

ZipImporter сохраняет у каждого импортированного ресурса путь к исходному архиву и расположение файла внутри него. Благодаря этому Unreal Engine может использовать стандартную команду **Reimport**.

Чтобы повторно импортировать ресурс, откройте его контекстное меню в Content Browser и выберите **Reimport** (или соответствующую команду повторного импорта для этого ресурса).

Исходный ZIP-архив должен оставаться доступен по сохранённому пути. Для ресурсов из вложенных архивов также должны быть доступны исходный внешний архив и вложенный ZIP-файл внутри него. Если архив был перемещён или удалён, повторный импорт завершится ошибкой, пока источник не будет возвращён или ресурс не будет импортирован заново.

### Существующие ресурсы

Импортёр допускает замену уже существующих ресурсов. Будьте внимательны при импорте в папку, где уже есть ресурсы с такими же именами пакетов: они могут быть заменены.

## Ограничения

- **Только ZIP.** Форматы RAR, 7z, TAR и другие архивы не поддерживаются.
- Файлы внутри архива должны поддерживаться стандартной системой импорта ресурсов Unreal Engine. Неподдерживаемые типы файлов не будут импортированы как ресурсы.
- Максимальная глубина вложенности ZIP-архивов составляет 8 уровней.
- Архив может содержать до 10 000 файлов, размер одного извлекаемого файла не должен превышать 512 МБ.
- Для повторного импорта исходный ZIP-архив должен оставаться доступен.

## Сборка из исходников

Этот раздел описывает сборку плагина в проекте и подготовку отдельного пакета для выбранной версии Unreal Engine. ZipImporter является редакторским плагином и не предназначен для включения в упакованную игру.

### Сборка в проекте Unreal Engine

1. Закройте Unreal Engine.
2. Откройте папку проекта и создайте каталог `Plugins`, если его ещё нет.
3. Клонируйте репозиторий непосредственно в каталог плагинов:

   ```bash
   git clone https://github.com/DontFWithTheJ/UnrealEngineZipImporter.git YourProject/Plugins/ZipImporter
   ```

4. Убедитесь, что файл `ZipImporter.uplugin` находится по пути `YourProject/Plugins/ZipImporter/ZipImporter.uplugin`.
5. Сгенерируйте или обновите файлы проекта, если этого требует ваша IDE.
6. Откройте файлы проекта в C++ IDE.
7. Соберите цель **Development Editor** для нужной платформы, например **Win64**.
8. Запустите проект. При необходимости включите плагин через **Edit → Plugins**.

Этот способ подходит для разработки, отладки и проверки изменений плагина непосредственно в проекте.

### Упаковка для версии Unreal Engine через Unreal Automation Tool

Чтобы собрать отдельный пакет плагина для определённой версии движка, используйте `BuildPlugin` из Unreal Automation Tool этой версии.

В Windows откройте командную строку и выполните команду, заменив пути на свои:

```bat
"C:\Path\To\UnrealEngine\Engine\Build\BatchFiles\RunUAT.bat" BuildPlugin -Plugin="C:\Path\To\ZipImporter\ZipImporter.uplugin" -Package="C:\Path\To\Output\ZipImporter" -TargetPlatforms=Win64
```

Аргументы:

- `RunUAT.bat` — скрипт Unreal Automation Tool из версии движка, для которой готовится сборка.
- `-Plugin` — путь к файлу `ZipImporter.uplugin`.
- `-Package` — каталог, в который будет помещён собранный плагин.
- `-TargetPlatforms=Win64` — целевая платформа Windows 64-bit. При необходимости укажите другую поддерживаемую платформу.

После завершения сборки проверьте каталог `-Package`. В нём должна находиться готовая папка `ZipImporter` с файлом `ZipImporter.uplugin` и необходимыми файлами сборки.

Чтобы использовать пакет в проекте, скопируйте папку `ZipImporter` в:

```text
YourProject/Plugins/ZipImporter/
```

Для установки в конкретную сборку движка используйте каталог плагинов этой установки, например:

```text
<UnrealEngine>/Engine/Plugins/Marketplace/ZipImporter/
```

Затем откройте проект и включите плагин через **Edit → Plugins**, если он ещё не включён.

**Важно:** запускайте `RunUAT.bat` из той версии Unreal Engine, для которой собираете плагин. Успешная сборка для одной версии не гарантирует совместимость с другими версиями. Если API движка изменился, исходный код плагина может потребовать адаптации.
